# 官网健康计数缺失值边界（2026-11-05）

## 发现与范围

当前云端 API22 的健康统计在解析缺失、空字符串或布尔值时，可能把未知计数当成 0；缺少本轮新增数时也可能误标为正常空扫。11 月 5 日对正式库的只读聚合检查显示，29 个现有来源的连续失败计数均完整且有效，已成功来源的本轮新增计数也均存在；本次没有发现由该边界造成的实际误报。

## 本地修正与验证

本地候选仅接受非负安全整数和十进制整数字符串；缺失、空值、布尔值及其他无效输入保持未知。没有新增数但已知扫描成功时保持健康状态，不假称空扫；即使失败次数缺失，已明确失败或部分失败的状态也继续如实显示。新增隔离测试先复现原有 `null` 被当成 0 的问题，修正后与定时健康候选一起完成 API、权限和文件回归 41 项。

此候选尚未发布，当前云端仍为 API22。若以后需要发布，必须基于当时的现网源码重新构建并核对全部文件，另行说明和获得授权；不能整体覆盖其他并行 API 更新。未修改正式数据、数据库结构、微信上传范围或付费分析开关。
