## 使用与人工复验

1. 在资源管理器创建 `D:\Engineering-Portfolio`，模块不会自动创建或移动作品目录。
2. 单个作品直接放入文件即可；关联文件较多的复杂项目保留原文件夹。例如：

   ```text
   D:\Engineering-Portfolio\
     转向节.SLDPRT          ← 独立卡片
     转向节.DWG             ← 独立卡片，同名不同扩展名不合并
     手绘.pdf               ← 独立卡片
     关联装配\              ← 只显示这一张文件夹项目卡片
       总成.SLDASM
       parts\子零件.SLDPRT  ← 仅出现在项目详情，不额外生成卡片
   ```

3. 在 `desktop/attention-desk` 按原方式运行 `pwsh -File .\start.ps1`；首次安装仍沿用原有 `-Install`。
4. 从侧栏进入「工程作品集」，或访问 `http://127.0.0.1:8765/?personal_view=portfolio`。开发入口为 `http://127.0.0.1:5173/?personal_view=portfolio`。
5. 将单个支持文件或项目文件夹放入总目录，点击「刷新作品」。搜索原始名称，或选择实际文件扩展名筛选。
6. 点击卡片查看文件名、类型、大小和修改时间。查看图片、在新标签页本地预览 PDF；独立文件点击「打开所在文件夹」，文件夹项目点击「打开作品文件夹」。
7. 修改/添加工程文件后刷新；将独立文件或项目目录改名、移出后刷新。重启本地工作台，核对作品仍依据原目录存在，原文件保持不变。
8. 「修改目录」只保存路径，不移动文件。保存失败保留输入并聚焦错误字段；未保存输入沿用既有离开确认。

支持 JPG、JPEG、PNG、PDF、SLDPRT、SLDASM、SLDDRW、DWG、DXF、STEP、STP，大小写不敏感。独立图片使用自身预览；其他独立文件按扩展名显示零件、装配、图纸或文档图标及类型文字。文件夹项目可选 cover.jpg / cover.png，之后以稳定文件名顺序选择图片，无图片显示文件夹图标。无需创建封面或额外目录。CAD/SW/STEP 文件只展示元数据，不转换、不渲染；文件位置、文件名及 SolidWorks 相对引用路径均保持原状，不自动分组或重排。

两种模式共同过滤：不支持的最终扩展名（包括 .bak、.sv$、.ac$、.dwl/.dwl2、.tmp 等）、点号/波浪号开头名称（包括 ~$ 锁文件）、Backup of / Backup (数字) of / Auto-recover save of 前缀，以及扩展名前的 .bak/.backup/.tmp/.temp/.old 标记（可带数字版本）。过滤只影响展示，不删除文件；普通标题含 backup 一词仍保留，不猜测已被人工重命名成普通作品名的副本。AutoCAD 的 .bak 与 .sv$ 用途可参见 [Autodesk 官方说明](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-Core/files/GUID-F930FDF6-0AAB-439E-8D14-6AC90BC4596F.htm)。

## 数据与访问边界

- 默认 `D:\Engineering-Portfolio`。路径偏好保存在 `%LOCALAPPDATA%\Eric OS\engineering-portfolio.json`，仅含 `root` 字段，独立于作品及 Git。
- 可用 `ERIC_PORTFOLIO_ROOT` 指定启动路径，界面不会覆盖该配置；取消该变量后恢复界面的路径偏好。
- 根目录必须是本机独立绝对目录，不能位于当前仓库或其他含 `.git` 的工作树中。拒绝盘符根、UNC/网络路径、符号链接和目录联接。
- 不跟随 Git 仓库、符号链接或目录联接；根层和项目内部共用上述过滤规则。解码后重新校验路径，阻止越界、绝对路径和 NTFS 附加流；独立文件预览不能借用其作品身份读取旁边的文件。
- 仅在 `server.main` 挂载接口，云端和手机 Collector 均不挂载。检查连接来源、Host、Origin、浏览器跨站标记及 desktop 运行身份，不向公网/局域网开放。
- `GET /api/personal/portfolio` 返回当前元数据，以 kind=file/folder 区分两种模式，原文件夹作品 ID 保持兼容；`PUT /root` 只保存路径；`GET /projects/{id}/preview/{file}` 只提供原始图片/PDF；`POST /projects/{id}/open` 为独立文件打开父目录，为文件夹作品打开自身。
- 无新表、迁移、作品记录、索引文件、原件副本或云端上传/同步。预览响应 `no-store`；封面地址包含修改时间/大小，覆盖同名封面后刷新会读取新内容。
- 最多 500 个作品；每件最多 2,000 个支持文件、20,000 个目录项、12 层嵌套。达到上限或读取失败有明确提示。卡片每批显示 24 个，并可「加载更多」。

## PWA 限制

公共 HTTPS Web/PWA 无法读取 D 盘。其「工程作品集」只显示限制和「打开本机作品集」链接，不调用作品接口，不将作品写入云端请求、离线队列或应用外壳缓存。链接要求存放作品的 Windows 电脑正在运行本地工作台；自定义端口从本地工作台进入。手机、iPad、其他电脑无法读取这些文件，不引入跨设备同步。
